Refactor SOP Management: Streamline Roles, Add Expiration Logic, and Enhance Dashboard

This commit introduces significant improvements to the SOP management system, focusing on role-specific workflows, automated expiration handling, and dashboard enhancements.

1. **Core Logic & Automation**:
   - **SOP Expiration**: implemented `CheckSopExpiration` console command to automatically identify and update expired SOPs.
   - **Scheduling**: Registered the expiration check in `console.php` to run daily.
   - **Observers**: Updated `DokumenSopObserver` to better handle state transitions and side effects.
   - **Notifications**: Refined `Notifikasi` model and `LoncengNotifikasi` Livewire component for more reliable real-time updates.

2. **Verifikator Role (Major Update)**:
   - **Resource Splitting**: decomposed monolithic keys into specialized resources for better usability:
     - `RiwayatSopResource`: Dedicated view for SOP history and tracking.
     - `SopAktifResource`: Streamlined view for currently active SOPs.
     - `SopSampahResource`: Management for archived or soft-deleted documents.
   - **Workflow Improvements**: Updated `DokumenSopResource` with enhanced verification pages (`Create`, `Edit`, `List`).
   - **Dashboard**: Updated `VerifikatorStats` for more relevant insights.

3. **Pengusul Role Refactor**:
   - **Cleanup**: Removed `DokumenSopResource` (redundant) and `SopStatsOverview`.
   - **Enhancement**: Refined `SopAktifResource` and `SopPengusulStats` to focus on relevant proposer metrics.

4. **Direksi Role Updates**:
   - **Dashboard**: Improved visualization in `SopStatusChart` and `TopUnitChart`.
   - **Resources**: Updated `DokumenSopResource` for executive review access.

5. **Frontend & UI**:
   - **Landing Page**: Polished `landing-page.blade.php` with better scrolling interaction and visual tweaks.
   - **General**: Improved navigation flows and mobile menu responsiveness.
